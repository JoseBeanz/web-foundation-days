About QuickNotes

QuickNotes is a minimalist note-taking tool built for speed and focus. It helps you capture ideas, tasks, and reminders instantly without distractions or complex setup. Whether you're a student, developer, or busy professional, QuickNotes keeps your thoughts organised and accessible.

This page explains how to use the app, highlights its key features, lists handy keyboard shortcuts, and gives you a way to send feedback directly to the team.

How to use QuickNotes

  1. Open the QuickNotes app or the home page in your browser.
  2. Click the “New note” button or press N to create a blank note.
  3. Type your content — it saves automatically as you type.
  4. Use the search bar to find notes by keyword, or organise them with tags.
  5. Access your notes from any device by signing in with your account.

Features

  • Lightning-fast note creation (no loading screens)
  • Autosave and offline support
  • Markdown-style formatting for quick styling
  • Tagging and full-text search
  • Dark mode and distraction-free writing
  • Sync across all your devices

Keyboard shortcuts

Shortcut Action
Ctrl + N (or Cmd + N) Create a new note
Ctrl + S (or Cmd + S) Save the current note manually
Ctrl + F (or Cmd + F) Search notes
Ctrl + B (or Cmd + B) Toggle sidebar
